# 맥세스 FAX통신 운영 가이드

## 📁 파일 구조

```
maxcess-fax/
├── index.html          ← 최신호 뷰어 (방문자가 보는 페이지)
├── archive.html        ← 지난 호 목록
├── admin.html          ← 관리자 입력 화면
├── data/
│   ├── archive-index.js   ← 전체 호수 목록 (새 호 발행시 1줄 추가)
│   └── 2025-34.js         ← 각 호 데이터 파일
└── images/
    └── 2025-34/           ← 해당 호 이미지 폴더
```

---

## ✏️ 매달 하는 일 (3단계)

### 1단계 — admin.html 열어서 내용 입력
- `admin.html`을 브라우저로 열기
- 각 항목 입력 후 **"파일 생성하기"** 클릭
- 자동으로 `data/2025-35.js` 파일이 다운로드됨

### 2단계 — 이미지 준비
- `images/2025-35/` 폴더 만들기
- 포스터, 강의 사진 등 이미지 파일 넣기

### 3단계 — 깃허브 업로드
1. 깃허브 저장소 접속
2. `Add file → Upload files` 클릭
3. 새 data 파일 + images 폴더 드래그앤드롭
4. `data/archive-index.js` 파일 열어서 맨 위에 한 줄 추가:
   ```js
   { 파일: "data/2025-35.js", 호수: "2025 / 35호", 발행월: "2025년 12월" },
   ```

---

## 📌 이미지 없을 때
- 이미지 파일명을 비워두면 (`""`) 해당 이미지 자리가 자동으로 사라집니다.
- 강제로 빈 박스가 표시되지 않습니다.

## 📌 경조사 없을 때
- admin.html에서 **"이번 호 경조사 없음"** 체크박스를 선택하면
- 뷰어에 "이번 호 경조사 소식이 없습니다"로 자동 표시됩니다.

---

## 🚀 깃허브 Pages 설정 (처음 한 번만)
1. 깃허브 저장소 → Settings → Pages
2. Source: `Deploy from a branch` → `main` → `/ (root)`
3. Save → 몇 분 후 `https://[계정명].github.io/maxcess-fax/` 로 접속 가능
